# Maintain Mining

Brand and design system for **Maintain Mining** — the Maintain group's
mining-sector brand: predictive maintenance and asset intelligence for mining
operations.

The brand is two-tone heavy machinery: **graphite `#303234`** (the grayish
black of the fleet — the logo colour) with **safety amber `#FFB800`** (the
equipment-yellow of the mine site) as the single working accent, over charcoal
grounds and desaturated wireframe terrain.
